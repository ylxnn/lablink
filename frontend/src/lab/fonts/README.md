# UI 字体

本项目随附 Noto Sans SC 的 WOFF2 UI 子集（常规及 Medium 字重），以避免依赖访问者系统安装的微软雅黑。字体来源为本机已安装的 Noto Sans SC (TrueType).otf 与 Noto Sans SC Medium (TrueType).otf，保留中文、拉丁字母和标点，并以独立 CSS 家族名 LabLink UI Sans 使用。

字体采用 SIL Open Font License 1.1，见同目录 OFL.txt。许可证来源：https://github.com/google/fonts/tree/main/ofl/notosanssc 。应用代码的 MIT 许可不替代字体的 OFL 许可。
